# Clip licenses

Every real clip used by the Gargantua Bench, with the license I read on its source page (Wikimedia Commons file
pages and their machine-readable `extmetadata`, fetched 2026-10-14). The clips live in `work/corpus/` and are
**never committed**; nothing derived from them (frames, contact sheets, volumes) is committed either, so the
share-alike terms of the CC BY-SA clips are not triggered by this repository. If you publish renders made
from a CC BY / CC BY-SA clip, credit the author as below (and release the render under the same license
for BY-SA).
